איך אנחנו משתמשים במידע

  • להציג את הפרופיל שלכם לאנשים שמתאימים להעדפות שלכם, ואת שלהם לכם.
  • לבדוק תמונות לפני שאחרים רואים אותן, ולטפל בדיווחים.
  • לשלוח התראות שהסכמתם להן, כמו Likes חדשים, התאמות והודעות.
  • לשמור על אבטחת החשבונות ולמנוע הונאות ושימוש לרעה.
  • להבין איך משתמשים באתר, בעזרת ניתוח נתונים ללא עוגיות.

אנחנו לא מוכרים את המידע האישי שלכם, ולא משתמשים בו לפרסום של צד שלישי.

מי רואה מה

חברים אחרים רואים את הפרופיל שלכם: שם, גיל, עיר, תמונות, תחומי עניין וכל תשובה שתבחרו להוסיף. ההודעות שלכם גלויות רק לכם ולאדם שאיתו אתם מדברים, חוץ ממקרים שבהם הודעה דווחה ונבדקת מטעמי בטיחות.

אנחנו משתפים מידע רק עם ספקי שירות שעוזרים לנו להפעיל את Bundle, כמו אחסון, שליחת מיילים ובדיקת תמונות, לפי חוזים שמגבילים את השימוש שלהם בו, או כשהחוק מחייב.

כמה זמן אנחנו שומרים את המידע

אנחנו שומרים את המידע שלכם כל עוד החשבון פתוח. כשאתם מוחקים את החשבון, אנחנו מוחקים את הפרופיל, התמונות, ההתאמות וההודעות, מלבד רשומות בטיחות שנשמרות עד 12 חודשים ורשומות שהחוק מחייב.
