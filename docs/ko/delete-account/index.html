Bundle 계정을 삭제하세요.

이 페이지에서는 Meet Bundle이 운영하는 데이팅 앱 Bundle의 계정을 삭제하는 방법과 데이터 처리 방식을 안내합니다.

이 페이지의 번역본은 편의를 위해 제공됩니다. 번역본과 영어 원문이 다를 경우 영어 원문이 우선합니다.

앱에서 삭제하기

  1. Bundle을 열고 Profile 탭으로 이동하세요.
  2. Settings(톱니바퀴 아이콘)를 탭하세요.
  3. Account details를 여세요.
  4. Delete account를 탭하고 확인하세요.

여기에서 삭제 요청하기

앱을 열 수 없거나 이미 삭제하셨나요? 요청을 보내 주시면 30일 이내에 계정을 삭제합니다. 삭제 전에 본인이 맞는지 이메일로 확인합니다.

삭제되는 항목

  • 프로필, 사진, 관심사, 답변
  • Likes, Winks, Sparks, 매칭, 대화
  • 이메일 로그인 정보와 계정 설정

보관되는 항목과 보관 기간

  • 사람들의 안전을 지키고 이용 정지된 사용자의 재가입을 막기 위해, 계정과 관련된 신고 및 안전 기록을 최대 12개월간 보관합니다.
  • 법률상 보관해야 하는 기록은 법률이 요구하는 기간 동안만 보관합니다.
  • 백업은 30일 이내에 덮어쓰입니다.
