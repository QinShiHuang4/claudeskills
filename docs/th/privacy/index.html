นโยบายความเป็นส่วนตัว

อัปเดตล่าสุด 21 พฤศจิกายน 2026

คำแปลของหน้านี้จัดทำขึ้นเพื่อความสะดวก หากคำแปลแตกต่างจากฉบับภาษาอังกฤษ ให้ถือฉบับภาษาอังกฤษเป็นหลัก

Meet Bundle คือแอปหาคู่ที่ดำเนินการโดย Or Berkovich นักพัฒนาอิสระในอิสราเอล นโยบายนี้อธิบายว่าเราเก็บข้อมูลอะไร เก็บเพื่ออะไร และคุณมีทางเลือกอะไรบ้าง

ข้อมูลที่เราเก็บ

ข้อมูลตัวอย่างเหตุผล
บัญชีอีเมล รหัสผ่าน (จัดเก็บเป็นค่าแฮชที่ปลอดภัย) และวิธีเข้าสู่ระบบเพื่อสร้างและรักษาความปลอดภัยของบัญชี
โปรไฟล์ชื่อที่แสดง วันเกิด เพศ ความสนใจในการออกเดต รูปภาพ ความสนใจ และคำตอบที่เลือกให้ได้เพื่อแสดงโปรไฟล์ของคุณและแนะนำผู้คน
ตำแหน่งที่ตั้งเมืองของคุณ และตำแหน่งของอุปกรณ์หากคุณอนุญาตเพื่อแสดงคนที่อยู่ใกล้คุณ คนอื่นจะเห็นเมืองของคุณและระยะทางโดยประมาณ ไม่เห็นตำแหน่งที่แน่นอน
กิจกรรมการกดไลก์ การขยิบตา Spark การข้าม การจับคู่ ข้อความ สถานะออนไลน์ และเวลาที่ใช้งานล่าสุดเพื่อให้ฟีเจอร์ของแอปทำงาน
ความปลอดภัยการรายงาน การบล็อก ผลการตรวจรูปภาพเพื่อรักษาความปลอดภัยของ Meet Bundle
อุปกรณ์ประเภทอุปกรณ์ เวอร์ชันแอป โทเค็นการแจ้งเตือน และข้อมูลวินิจฉัยข้อผิดพลาดเพื่อส่งการแจ้งเตือนและแก้ไขปัญหา
เซสชันของบัญชีและการยอมรับนโยบายที่อยู่ IP ข้อมูลเบราว์เซอร์หรือแอป เวอร์ชันนโยบาย และเวลาที่ยอมรับเพื่อจัดการเซสชัน ปกป้องบริการ และบันทึกการยอมรับนโยบาย

เราต้องใช้ข้อมูลเข้าสู่ระบบและข้อมูลโปรไฟล์ที่จำเป็นเพื่อสร้างบัญชี เราใช้วันเกิดเพื่อตรวจสอบว่าคุณมีสิทธิ์ใช้งานหรือไม่และเพื่อแสดงอายุ หากต้องการแก้ไขวันเกิด โปรดติดต่อฝ่ายช่วยเหลือ

คุณเลือกได้ว่าจะระบุรสนิยมทางเพศหรือไม่ ผู้ดูแลที่ได้รับอนุญาตสามารถดูได้ สมาชิกคนอื่นจะเห็นข้อมูลนี้ก็ต่อเมื่อคุณเลือกแสดงบนโปรไฟล์ คุณซ่อนหรือลบข้อมูลนี้ได้ในแอป

คุณเลือกเมืองเพื่อค้นหาคนใกล้เคียงและปิดสิทธิ์เข้าถึงตำแหน่งในการตั้งค่าโทรศัพท์ได้ เมื่อปิดสิทธิ์แล้ว ระบบจะหยุดรับข้อมูลตำแหน่งใหม่ เลือกค้นหาตามเมืองเพื่อแทนที่ตำแหน่งอุปกรณ์ที่บันทึกไว้

เราใช้ข้อมูลอย่างไร

  • แสดงโปรไฟล์ของคุณให้คนที่ตรงกับความต้องการของคุณ และแสดงโปรไฟล์ของพวกเขาให้คุณ
  • ตรวจรูปภาพก่อนที่คนอื่นจะเห็น และดำเนินการกับการรายงาน
  • ส่งการแจ้งเตือนที่คุณยินยอม เช่น Likes ใหม่ การแมตช์ และข้อความ
  • รักษาความปลอดภัยของบัญชี และป้องกันการฉ้อโกงและการใช้งานในทางที่ผิด
  • เราใช้ Cloudflare Web Analytics ซึ่งไม่ใช้คุกกี้ เพื่อวัดการเข้าชมและประสิทธิภาพของเว็บไซต์

เราไม่ขายข้อมูลส่วนบุคคลของคุณ และไม่นำไปใช้เพื่อโฆษณาของบุคคลที่สาม

เมื่อกฎหมายกำหนด เราใช้ฐานสัญญาเพื่อให้บริการฟังก์ชันหลัก ฐานประโยชน์โดยชอบด้วยกฎหมายสำหรับการรักษาความปลอดภัยและป้องกันการใช้งานในทางที่ผิดเท่าที่กฎหมายอนุญาต ฐานความยินยอมสำหรับวัตถุประสงค์ที่ต้องขอความยินยอม และฐานหน้าที่ตามกฎหมายสำหรับการเปิดเผยหรือเก็บรักษาที่กฎหมายกำหนด

ใครเห็นอะไรบ้าง

สมาชิกดูโปรไฟล์และข้อความที่คุณส่งให้พวกเขาได้ เจ้าหน้าที่ที่ได้รับอนุญาตตรวจสอบข้อมูลโปรไฟล์ รายงาน ข้อความที่แนบในรายงาน และบางส่วนของเนื้อหาที่ระบบกลั่นกรองอัตโนมัติระบุไว้ได้

ผู้ให้บริการของเรารวมถึง Render สำหรับโฮสติ้ง AWS สำหรับจัดเก็บรูปภาพ Resend สำหรับอีเมล Firebase Cloud Messaging สำหรับการแจ้งเตือนแบบพุช Sentry สำหรับวินิจฉัยข้อผิดพลาด และ Cloudflare สำหรับวิเคราะห์เว็บไซต์ เราอาจเปิดเผยข้อมูลตามที่กฎหมายกำหนดด้วย

ระบบที่ให้บริการจริงและที่จัดเก็บรูปภาพอยู่ในสิงคโปร์ ผู้ให้บริการอาจประมวลผลข้อมูลในประเทศอื่น ติดต่อเราเพื่อสอบถามรายละเอียดการโอนข้อมูลระหว่างประเทศและมาตรการคุ้มครองที่ใช้

เราเก็บข้อมูลนานเท่าใด

เมื่อคุณลบบัญชี เราจะซ่อนโปรไฟล์ ยุติการจับคู่ และลบเนื้อหาข้อความที่คุณส่ง บันทึกบัญชี การจับคู่ และข้อความบางส่วนยังคงอยู่ ระบบจะลบรูปภาพเบื้องหลัง โดยสำเนาส่วนตัวสำหรับกู้คืนและข้อมูลสำรองมีระยะเวลาจัดเก็บแยกกัน

แอปเก็บรูปภาพที่คุณดูไว้ชั่วคราวในแคชของอุปกรณ์เป็นเวลาไม่เกินเจ็ดวัน

รายงานและสำเนาข้อความที่รวมอยู่ในรายงานอาจยังคงอยู่หลังการบล็อก ยกเลิกการจับคู่ หรือลบบัญชี เราเก็บบันทึกด้านความปลอดภัยเท่าที่จำเป็นเพื่อสอบสวน บังคับใช้กฎ และดำเนินการเกี่ยวกับข้อเรียกร้องทางกฎหมาย และเก็บบันทึกอื่นตามที่กฎหมายกำหนด

เมื่อเปิดใช้การตรวจสอบการติดตั้ง เราจะเก็บตัวระบุการติดตั้งแอปในรูปแบบแฮชเพื่อช่วยตรวจจับการใช้งานในทางที่ผิด การเชื่อมโยงกับบัญชีจะหมดอายุ 90 วันหลังจากตรวจพบครั้งล่าสุดหรือเมื่อมีการลบบัญชี

ลบบัญชีของคุณ

ทางเลือกและสิทธิ์ของคุณ

  • แก้ไขหรือลบข้อมูลโปรไฟล์ได้ทุกเมื่อในแอป
  • ปิดตำแหน่งที่ตั้งและการแจ้งเตือนในการตั้งค่าโทรศัพท์
  • คุณเลือกได้ว่าจะแชร์สถานะออนไลน์และเวลาที่ใช้งานล่าสุดหรือไม่ในการตั้งค่าการมองเห็นในแอป
  • ขอสำเนาข้อมูล ขอแก้ไข หรือขอลบข้อมูลทางอีเมล: support@meetbundle.com

คุณอาจมีสิทธิ์ถอนความยินยอม คัดค้านหรือขอจำกัดการประมวลผล ขอสำเนาข้อมูลในรูปแบบที่โอนย้ายได้ หรือร้องเรียนต่อหน่วยงานคุ้มครองข้อมูล ทั้งนี้ขึ้นอยู่กับกฎหมายที่ใช้บังคับ
