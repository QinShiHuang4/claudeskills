我们的隐私政策解释了我们如何处理个人信息. 我们的儿童安全标准解释了我们对儿童安全问题的规则和报告选项。

使用一个个人帐户. 保持您的登录身份证保密,并立即联系支持,如果您怀疑未经授权的访问. 保持控制自己的帐户,并遵守暂停,禁令和其他限制。

使用 Discover 查找个人资料,发送 Winks 向您致敬,发送 Likes 向您表达兴趣,或发送 Spark 以包含一个短信与 Like。 你可以聊天,当一个比赛设置。 建议可以使用您的偏好、位置、兴趣和活动。 每个会员都选择是否应对或匹配。 功能可用性、可见性和使用限制可能有所不同。

使用个人约会和社交联系的服务。 尊重其他会员的界限,包括当他们拒绝接触、停止响应、不匹配或阻止您时。

我们可能会拒绝或删除内容,限制个人资料的可见性或互动,或暂停或关闭帐户,以执行本条款,调查可疑违规行为,保护个人,或履行法律义务。 我们可以在安全、安全或法律要求时立即采取行动。 联系支持,请求审查决定。 我们将根据适用法律要求提供通知、理由和审查选项。
