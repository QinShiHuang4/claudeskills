Verwenden Sie Discover, um Profile zu finden, senden Sie Winks, um Hallo zu sagen, senden Sie Likes, um Interesse auszudrücken, oder senden Sie einen Spark, um eine kurze Nachricht mit einem Like zu enthalten. Sie können chatten, wenn ein match eingerichtet wird. Empfehlungen können Ihre Präferenzen, Standort, Interessen und Aktivitäten nutzen. Jedes Mitglied entscheidet, ob es zu reagieren oder zu treffen ist. Funktionelle Verfügbarkeit, Sichtbarkeit und Benutzungsgrenze können unterschiedlich sein.

Fotos werden überprüft, bevor andere Mitglieder sie sehen können, und neue Profile können für die Überprüfung gehalten werden. Foto Genehmigung spiegelt eine Moderationsentscheidung aus. Verwenden Sie Ihre eigene Entscheidung über die Identität eines Mitglieds, Ansprüche, Kompatibilität, und ob Sie persönlich zu treffen.
